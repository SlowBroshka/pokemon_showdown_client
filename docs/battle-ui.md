# Этап 6: экран боя и сквозная проверка

Задача #35. Реализация и локальная приёмка: 27 октября 2026 года.

## План PR

1. Отобразить участников, ход, активных Pokémon, HP/статусы, Tera и результат.
2. Подключить атаки с PP, добровольную/вынужденную замену и Tera к capture/submit.
3. Показать ожидание, отказ, неизвестный результат отправки и блокировки.
4. Добавить русский/английский интерфейс и проверку узкого экрана с крупным текстом.
5. Проверить путь сообщение → модель → кнопка → команда, собрать Android/Linux.
6. Проверить подготовленный бой на локальном движке и документировать границы.

## Интерфейс

BattlePanel встроен в ConnectionScreen и получает app-owned BattleDecisionController.
Панель не управляет соединением. Публичные HP остаются в сообщённой шкале;
приватная команда показана отдельно с пометкой «последний приватный снимок».
Никаких предположений о скрытых HP/PP нет. Имена и названия сущностей остаются
серверными строками; интерфейс и статусы переведены. HTML/raw не исполняются.
Журнал показывает последние 20 структурированных действий из ограниченного журнала.

Кнопки захватывают решение при построении, а не при нажатии: отложенный callback
не отправит слот из нового запроса. Tera сбрасывается при каждой новой revision,
даже если rqid не изменился. Недоступные атаки/замены показаны отключёнными.
Повторное нажатие не посылает вторую команду. После Invalid choice показан
безопасный перевод, без текста ответа сервера. Остальные блокировки определяются
контроллером; экран не пытается самостоятельно признать ход принятым.

## Локальный стенд

`tool/local_battle_server.cjs` — небольшой loopback-сервер с настоящим
BattleStream из официального Pokémon Showdown и автоматическим соперником.
Это **не** полный публичный сервер: в нём нет входа в аккаунт, рейтинга,
матчмейкинга и production-инфраструктуры. Оболочка добавляет init/title/rqid,
обрабатывает join/leave и передаёт choose движку. Бой рассчитан на поддержанный
набор механик Gen 9 singles. При LOCAL_REJECT_FIRST=1 первый отказ создаёт
тестовая оболочка; дальнейшие решения, HP, Tera и результат вычисляет движок.

Проверенная ревизия движка:
`b354a81f11003a03f0dcd1dafd4edc641e6763bd`.
Требуется Node.js 22.18+; установка и сборка выполняются вне репозитория клиента:

```sh
git clone https://github.com/smogon/pokemon-showdown.git /tmp/showdown-engine
cd /tmp/showdown-engine
git checkout b354a81f11003a03f0dcd1dafd4edc641e6763bd
npm ci
node build
```

Из репозитория клиента:

```sh
SHOWDOWN_PATH=/tmp/showdown-engine LOCAL_REJECT_FIRST=1 node tool/local_battle_server.cjs
flutter run -d linux --dart-define=SHOWDOWN_LOCAL=true
# Или:
flutter run -d emulator-5554 --dart-define=SHOWDOWN_LOCAL=true
```

В приложении указать сервер:

- Linux: `ws://127.0.0.1:8000/showdown/websocket`.
- Стандартный Android-эмулятор: `ws://10.0.2.2:8000/showdown/websocket`.
- Комната `battle-local`: замена/Tera/атаки против Splash.
- Комната `battle-local-force`: первый Pokémon слабый, после обморока нужна замена.

Пароль и авторизация не требуются; панель аккаунта для этого сервера недоступна.
Новый сокет/повторный вход создаёт новый независимый тестовый бой. Сервер слушает
только 127.0.0.1. Остановить его можно Ctrl+C.

WS допускается только при SHOWDOWN_LOCAL=true и вне product-сборки, только для
localhost, 127.0.0.1, ::1 и адреса хоста эмулятора 10.0.2.2. Обычные сборки требуют
WSS. Android cleartext-разрешение находится только в debug manifest; проверки
сертификатов WSS не отключаются. Учетные данные в URL не допускаются.

- Полный набор: 301 тест прошёл, 2 opt-in сетевых сценария пропущены по умолчанию.
- Отдельный opt-in прогон обоих сценариев на настоящем локальном движке прошёл:

- Android debug APK и Linux debug сборки выполнены.
- Widget-тесты RU/EN: повторное нажатие, устаревший callback, сброс Tera, forced
  switch, unavailable/wait/null, повреждённые данные, результат и stale.

Команды воспроизведения при запущенном стенде:


Реальный движок выявил и помог исправить расхождения синтетического корпуса:
пустой `side.pokemon[].terastallized` означает отсутствие превращения; `raw` и
`-nothing` — декоративные сообщения. Добавлены регрессионные проверки.
Пустой canTerastallize всё ещё считается ошибкой: это другое поле.

## Ограничения

Полный публичный Gen 9 Random Battle не сертифицирован: неизвестные значимые
события и механики по-прежнему блокируют выбор. Публичный матчмейкинг не запускался.
Локальная приёмка подтверждает UI, сокет, решения и поддержанный набор механик,
но не заменяет будущую проверку полного сервера, авторизованного аккаунта,
случайных команд и устройства Android вне эмулятора. Полный интерпретатор
scenarios.json не добавлен; его поведение покрывается отдельными исполняемыми
тестами, а не чтением заранее записанного expected.
